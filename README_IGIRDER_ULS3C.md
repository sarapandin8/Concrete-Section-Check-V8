# IGIRDER.ULS3C — Flexure Legend Readability Polish

Presentation-only closeout for `Precast I-Girder: Bridge · Precast Composite Girder` ULS Flexure charts.

- Shortens the stage-specific flexure legend to the accepted Concrete Section Pro chart language: `Demand Mux`, `φMn`, and `Gov. flexure`.
- Keeps the governing-demand point and on-chart `Governing demand` annotation, but removes its redundant legend entry.
- Reserves fixed legend entry width and slightly more bottom margin so horizontal legend text does not collide when the browser scales the chart.
- Applies to both `Construction — Noncomposite` and `Final — Composite`, including the Final demand-only preview before capacity is calculated.
- Does **not** change demand, capacity, prestress, neutral-axis, effective-width, D/C, status, cache, or any engineering equation.
