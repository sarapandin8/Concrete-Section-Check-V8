# CROSSBEAM.PTLOSS3B2B1 — Gravity-only compression-contact kernel

This milestone introduces the first unilateral falsework-contact solver for the Portal Frame Crossbeam stressing-stage workflow while preserving the accepted fixed-base linear-response QA. The Crossbeam self-weight stage is solved with rigid, frictionless, vertical contact available at every Crossbeam mesh node. Contact reaction is defined positive upward/compressive and separation gap positive upward; the active-set iteration removes any active node requiring tensile reaction and re-closes any open node that penetrates the falsework datum. The accepted conditions are `R >= 0`, `g >= 0`, and `R·g = 0`, with global force/moment equilibrium checked after convergence.

The UI adds a separate gravity-only contact section with contact-reaction and gap diagrams, active/open station status, iteration history, complementarity residuals, independent closure/lift-off/re-closure/symmetry benchmarks, and current-input contact mesh evidence. For a fully active rigid support, mesh review checks stable total contact reaction and monotonic decay of the residual between-contact moment/displacement fields rather than misclassifying convergence-to-zero percentages as instability. Contact diagnostics are cached by an isolated input fingerprint and are never persisted to Project JSON or passed to Result Summary, Report/QA, or production results.

The generic linear frame solver now accepts individual restrained DOFs so vertical contact can be enforced without falsely fixing axial displacement or rotation. Existing full-node fixed-base behavior remains backward compatible. The browser-print guard also keeps the `C. Equivalent tendon nodal actions` heading with its table.

This is deliberately a **gravity-only QA foundation**. It does not apply post-anchor tendon loads, does not update contact after stressing groups, and does not release Primary/Secondary Prestress, source-derived `f_cgp`, Elastic Shortening, `P after ES`, `Pe/Pe_eff`, Result Summary, or Report/QA solver credit.
