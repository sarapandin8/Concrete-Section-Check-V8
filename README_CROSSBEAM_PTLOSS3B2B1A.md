# CROSSBEAM.PTLOSS3B2B1A — Contact-reaction semantics and audit completeness

This milestone hardens the accepted gravity-only rigid compression-contact kernel without changing its active-set equations, contact state, reactions, or structural response. Raw contact reaction remains a nodal solver quantity `Rnode` in kN. Each contact station now receives a geometric tributary length based on half the spacing to adjacent contact nodes, and the engineering plot reports the line-equivalent reaction `q = Rnode / Ltrib` in kN/m so reaction distributions can be compared meaningfully across contact meshes. The raw nodal reactions and tributary lengths remain visible in the solver audit, and `Σ(q·Ltrib) = ΣRnode` is preserved exactly.

The contact source is now explicit about its physical idealization: perfectly rigid vertical compression-only contact, zero falsework settlement, no finite support-spring stiffness, vertical contact only, and no interface friction or horizontal force transfer. This is a QA idealization, not a calibrated falsework model.

The active-project contact station evidence is rendered as complete static print tables in bounded chunks rather than a scroll-only dataframe, so all candidate stations can appear in browser-print QA. The contact expander is allowed to split between static table chunks, while each chunk remains indivisible. Floating-point negative zero is normalized in user-facing complementarity text, and the temporary-support wording now distinguishes the released gravity active-set route from the still-locked incremental prestress contact stages.

No frame stiffness, self-weight, active-set release/re-close rule, complementarity tolerance, contact reaction, gap, mesh sensitivity, tendon load, Friction/Wobble, Anchorage Set, Elastic Shortening equation, Project JSON schema, Result Summary, Report/QA, or production-result handoff is changed. Incremental tendon-group stressing, prestress-induced lift-off, source-derived `f_cgp`, final Elastic Shortening, `P after ES`, and `Pe/Pe_eff` remain locked.
