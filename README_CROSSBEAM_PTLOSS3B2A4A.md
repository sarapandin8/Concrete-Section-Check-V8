# CROSSBEAM.PTLOSS3B2A4A — Bond-system semantics and audit presentation polish

This targeted closeout clarifies that the Tendon System source represents the **final tendon bond system**, not the grout condition at the instant of stressing. Canonical values are now `Not specified`, `Bonded after grouting`, and `Permanently unbonded`; legacy `Bonded / grouted` and `Unbonded` values migrate conservatively through the tendon schema without inferring any value from Internal/External location. The bulk action starts at an explicit `Select final bond system…` placeholder and remains disabled until the engineer makes a choice. Stale PTA1/ACI 423.10R and user-facing milestone references are removed. The response-event audit is split into three print-readable tables for station/source mapping, local-moment/reference-axis interpretation, and equivalent tendon nodal actions. No frame, friction, anchorage-set, mesh, or Elastic Shortening equations change; contact/lift-off, source-derived f_cgp, final ES, Pe/Pe_eff, Result Summary, and Report/QA credit remain locked.
